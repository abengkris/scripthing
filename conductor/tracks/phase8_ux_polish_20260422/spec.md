# Specification: Phase 8 - UX & Feature Polish

## Overview
This track focuses on enhancing the user experience in the screenplay writing interface by implementing essential utility features as outlined in the development roadmap (Phase 8).

## Functional Requirements
- **Word/Page Count Status Bar**: Display real-time word count and estimated page count in the editor's status bar using client-side calculation.
- **Character Appearance Report**: Generate a report detailing character names and their appearance frequency.
- **Find & Replace**: Implement a global basic text find & replace functionality across the active script.
- **Keyboard Shortcut Reference Panel**: Create a panel summarizing all available keyboard shortcuts for quick reference.

## Acceptance Criteria
- Word/Page count updates accurately during typing.
- Character appearance report can be generated on demand.
- Find & Replace operates reliably across the document content.
- Shortcut reference panel is accessible and accurate.

## Out of Scope
- Advanced screenplay analytics dashboard.
- Context-aware screenplay element filtering (e.g., character-only replacement).
