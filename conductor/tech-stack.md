# Tech Stack

## Frontend
| Technology | Purpose |
|---|---|
| shadcn/ui | Component library (Radix UI + Tailwind, copied into repo |
| TypeScript | Type safety |
| Vite | Build tool & dev server |
| TailwindCSS | Styling |
| Tiptap | Rich text / screenplay editor (ProseMirror-based) |
| Zustand | Global state management |
| React Query | Server state & API caching |
| React Router | Client-side routing |
| Lucide React | Icon set |
| idb | IndexedDB persistence |
| lodash.debounce | Performance optimization for auto-save |

## Backend
| Technology | Purpose |
|---|---|
| Node.js | Runtime |
| Fastify | HTTP framework |
| TypeScript | Type safety |
| Prisma | ORM |
| SQLite | Database |
| Zod | Schema validation |
| JWT (jose) | Stateless authentication |
| bcrypt | Password hashing |
