# Product Guidelines

## Design Principles
- **Distraction-Free:** The UI should be minimal, keeping the focus on the writing area.
- **Industry Standard:** Formatting must strictly adhere to professional screenplay standards (Courier Prime font, margins, capitalization).
- **Privacy First:** Data remains on the user's machine. AI features must be explicitly opted-in and require user-supplied keys.

## UX Principles
- **Keyboard-Centric:** Frequent tasks (formatting, switching modes) should be accessible via keyboard shortcuts.
- **Predictable:** Screenplay element transitions should be intuitive and automatic (e.g., hitting "Enter" in a scene heading should automatically move to action mode).
- **Responsive:** The UI should remain fluid even with long, complex scripts.

## Prose & Communication
- **Clear & Concise:** AI feedback and UI messages should be direct, helpful, and avoid unnecessary jargon.
- **Professional Tone:** The application should feel like a tool for professional writers.
